## 작업 방식

원고 본문은 `src/manuscript.md`(pandoc 마크다운) 한 파일에서 고칩니다. 판마다 git 커밋이 남으므로 무엇이 바뀌었는지 정확히 비교할 수 있습니다.

```bash
python3 build/build.py v1.1 2026-10-25   # src/manuscript.md → 투고원고 .docx
python3 build/report.py v1.1             # changes/v1.1.json → 수정내역서 .docx
```

- `build/schedule.json`: 날짜별 판 번호와 주제(수정내역서 7장의 일정표도 이 파일에서 만듭니다)
- `changes/vX.Y.json`: 그날의 수정 요약, 수정 전/후 목록, 분량, 저자 확인 필요 사항, 다음 계획
- `figures/`: 그림 원본(image1 = Fig. 1 상태도, image2 = Fig. 2 개념도)

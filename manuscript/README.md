### v2.6 — 2026-10-29 (Ⅲ장 표·그림 정합)
〈그림 1〉, 〈표 2〉, 〈표 3〉과 본문을 하나씩 대조했습니다.
1. **〈그림 1〉과 〈표 3〉의 충돌:** 그림 설명은 "굵은 실선 = 큰 확률, 점선 = 작은 확률"이라고 했습니다. 그런데 그림은 인접 후퇴(S0→B, S1→S0, S2→S1, S3→S2)를 점선으로 그렸고, 〈표 3〉은 이 칸을 큰 값(●)으로 예측합니다. 그래서 그림 설명을 고쳤습니다.
   - 실선은 전진 방향의 대표 경로, 점선은 해소·후퇴·도약·회귀·재진입 경로로 다시 정의했습니다.
   - 예측 크기는 〈표 3〉을 따른다고 밝혔습니다.
   - 비인접 경로는 S2→E1 도약만 그렸다고 적었습니다.
   - 그림에서 실패 후 회귀(N → R₀) 화살표가 S1을 가리키지만, 도착 국면을 S1로 고정하지 않는다고 적었습니다.
   - 그림 파일은 그대로 두었습니다.
2. **〈표 2〉 N·S4 행:** 본문은 새 방식 사용비율 u(Ⅳ장 5절)와 잠정 기준 .80(Ⅶ장 3절)을 쓰는데, 표에는 이 수치가 없었습니다. N 행에는 "u가 잠정 기준(.80) 미달"을, S4 행에는 "반복성(u ≥ .80, 잠정)"을 넣었습니다.
3. **Ⅲ장 3절 마지막 문단:** "6국면"은 5개 잠재 국면과 1개 전환 사건이라는 설명과 B·N이 경계 상태라는 설명이 2절과 거의 같은 문장으로 되풀이되었습니다. 2절을 가리키는 한 문장으로 줄였고, S0 검정 문장은 남겼습니다.
4. 판 표시를 v2.6으로 바꿨습니다.

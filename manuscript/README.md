## 수정 이력

### v2.1 — 2026-10-24
1. 오탈자: "궁적" → "궤적"(7곳), "곳바로" → "곧바로"(1곳).
2. Ⅰ장 4절 핵심 정의: 워드 본문에 그대로 찍혀 있던 `**` 기호를 지우고 체제·국면·전이·체제 전환·임계를 굵은 글씨로 바꿨습니다.
3. 인용–참고문헌 대조
   - 본문에 있으나 참고문헌에 없던 Helmich et al.(2021)을 추가했습니다(*Current Opinion in Psychology*, 41: 51-58). DOI는 확인하지 못해 넣지 않았습니다.
   - 참고문헌에 있으나 본문에 인용되지 않던 Bacharach(1989)를 Ⅴ장 4절 첫 문장에 인용했습니다("이론은 반증 가능성과 효용으로 평가되어야 한다는 기준").
   - 나머지 인용은 저자·연도가 참고문헌과 일치했습니다.
4. 제목 아래 "Oct 18, 2026 · @Sangho"를 "[저자 정보: 심사용 원고에서 삭제] 수정본 v2.1(2026. 10. 24.)"로 바꿨습니다.

**저자 확인 필요**
- 원고 첫머리 메모는 근거 문서를 「명세서 **제3판**」(2026. 10. 17.)으로 적고 있으나, 저장소 기준 문서는 제2판(2026-09-27)입니다. 제3판이 맞는지 확인해 주세요.
- 학회 투고규정 원문(분량, 초록 글자 수)은 이 환경에서 학회 누리집에 접속하지 못해 직접 확인하지 못했습니다. 검색 결과로는 참고문헌 포함 30매 기준, 국문 문헌 → 외국 문헌 순, 영문초록은 본문·참고문헌·부록 뒤입니다. 현재 원고는 영문초록이 참고문헌 뒤, 부록 앞에 있으므로 11-04 판에서 순서를 맞출 예정입니다.

# 문항은행 변경 기록

## bank v0.1 — 2026-10-17 (첫 주간보고 W00)

- **출처**: `docs/주간설문_문항안.md`(커밋 2213b2c)의 국면 40문항, E1 8문항, 비용 9문항을 옮겨 왔습니다(`legacy_id` 열).
- **구조 변경**: 국면별로 공통 5문항(C) + 대학생 맥락 2문항(U) + 직장인 맥락 2문항(W)으로 나눴습니다. 응답자는 국면마다 7문항을 받습니다.
- **회상기간**: 모든 국면·비용 문항에 '지난 7일 동안'을 문항 앞에 넣었습니다. 관성 α(IA)만 성향 문항이라 회상기간이 없습니다.
- **신규 문항 11개**: S0-U02, S0-W02, S1-U02, S1-W02, S2-U01, S2-U02, S2-W01, S2-W02, S3-U02, S3-W02, S4-U01. 근거는 대학생·직장인 맥락의 내용 포괄성입니다(COSMIN 포괄성 기준; Terwee 외, 2018).
- **보류(hold) 11개**: S0-8, S0-3, S1-3, S1-5, S2-5, S2-6, S2-8, S3-6, S3-8, S4-8, CM-3. 다른 국면·비용 문항과 내용이 겹치거나 사건형이라 국면 문항으로 부적합한 문항입니다. 삭제가 아니라 보류이며, 전문가 정의 변별도 평정 뒤 다시 판단합니다.
- 배포한 조사판은 없습니다.

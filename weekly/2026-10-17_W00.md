## ① 연구설계 초안

### 1.1 연구 질문

| 번호 | 질문 | 검증 대상 |
|---|---|---|
| RQ1 | 6국면(S0·S1·S2·S3·S4 상태 + E1 사건)을 대학생과 직장인이 서로 다른 경험으로 구별하는가? | 정의 수준 구별(전문가·일반 평정자) |
| RQ2 | 국면 문항이 5개의 구별되는 잠재변인(S0~S4)으로 측정되는가, 아니면 더 적은 차원(인접 국면 병합, 단일 연속선)으로 충분한가? | 측정 수준 구별(EFA·CFA·전개 IRT) |
| RQ3 | 측정 구조가 대학생과 직장인, 그리고 시점 간에 같은가? | 측정동일성 |
| RQ4 | 사람들이 국면을 S0→S1→S2→S3→E1→S4 순서로 거치는가, 아니면 건너뛰기·되돌아가기가 흔한가? | 순서 검증(종단) |
| RQ5 | 주간 국면 점수와 비용비가 E1 사건(독립 기록으로 확인)의 시점을 예측하는가? | 예측타당도 |

RQ1·RQ2와 RQ4는 **확인하려는 주장이 아니라 반증 가능한 가설**로 둡니다. "6국면이 구별되지 않는다" 또는 "순서가 없다"는 결과도 모형 개정의 근거가 되는 유효한 결과입니다.

### 1.2 설계 개요

| 항목 | 초안 |
|---|---|
| 대상 | 대학생 1~4학년, 직장인 입사 1~4년차. 2집단 × 4수준 = 8셀 |
| 변화 대상 | `{새 방식}` = **생성형 AI를 활용한 [학업/업무] 방식**(기존 초안의 결정을 유지. 미해결 쟁점 2) |
| 측정 단위 | 개인, 주(週) |
| 기본 설계 | **동일 참여자 주간 종단조사**(0주 기준조사 + 1~12주 주간조사 + 종료조사). 단, 문항 구조를 확정하기 전에는 횡단 표본(예비조사·EFA·CFA)으로 측정도구를 먼저 다듬습니다. |
| 문항 구성 | 국면 문항(공통 25 + 맥락 10) + E1 사건 8 + 비용 5 + 관성 3 + 자기배치 1 + 주간 상황 3 + 주의 확인 1 + 성찰 1 |
| 독립 확인 자료 | E1 사건의 기록(과제 제출 이력, 업무 기록, 도구 사용 로그). 별도 동의자만 연결 |
| 개발 절차 | 내용타당도 → 인지면담 → 예비조사 → EFA → CFA·신뢰도·타당도 → 집단 간 측정동일성 → 종단(시점 간 측정동일성, 순서 검증) |

### 1.3 이 설계에서 주의할 세 가지

1. **단봉형(이상점) 반응**: 국면 문항은 "그 국면에 있을 때만" 높게 답하는 반응을 보일 가능성이 큽니다. 이때 일반 요인분석은 요인을 잘못 쪼개거나 합칠 수 있으므로, 전개 IRT(GGUM)를 대안모형으로 반드시 비교합니다(van Schuur & Kiers, 1994; Roberts 외, 2000).
2. **국면 점수로 전이를 정의하는 순환논증**: E1은 리커트 요인이 아니라 사건 문항과 외부 기록으로 측정합니다.
3. **패널 조건화**: 매주 같은 문항에 답하는 것 자체가 응답자의 생각을 바꿀 수 있습니다(Warren & Halpern-Manners, 2012). 참여 시작 시점을 나눈 신규 유입 집단(refreshment)을 두고 비교하는 안을 검토합니다(미해결 쟁점 8).

### 2.3 "6국면이 구별되는가", "순서대로 진행되는가"를 검증 대상으로 두는 방식

| 가설 | 지지하는 결과(예시, 사전등록에서 수치 확정) | 반증하는 결과 | 확인 단계 |
|---|---|---|---|
| H-D1 정의 구별 | 정의 변별도 평정에서 각 문항이 자기 국면 정의에 가장 잘 맞음(Colquitt 외, 2019). 인접 국면 오분류가 낮음 | S1·S2·S3 문항이 서로 자주 오분류됨 | 4.1 |
| H-D2 측정 구별 | 5요인(S0~S4) 모형이 인접 병합 4요인, 단일 요인, 양극 2요인보다 낫고, 국면 간 상관 신뢰구간 상한 < .85(Rönkkö & Cho, 2022) | 병합 모형과 차이가 없음, 인접 국면 상관 ≥ .90 | 4.4~4.5 |
| H-D3 E1 구별 | S3 점수가 E1 직전에 가장 높고, S4 점수는 E1 뒤에 오름 | E1 전후로 S3·S4 점수 변화가 없음 | 4.7 |
| H-O1 순서(횡단) | 전개 IRT에서 문항 위치가 S0→S4 순서로 배열됨 | 위치 순서가 뒤섞임 | 4.4 |

| H-O3 경유 | E1이 일어난 사람 대부분이 그 전에 S3를 거침 | S3를 거치지 않은 E1이 흔함 | 4.7 |

- "반드시 순서대로"는 가장 강한 주장이므로, **회귀(되돌아감)와 건너뛰기를 허용하는 모형**을 함께 비교합니다. 상세한 대안모형 목록은 [`docs/연구방법.md`](../docs/연구방법.md) 5장을 따릅니다.
- 12주 안에 실제로 국면을 옮기는 사람이 적으면 H-O2는 검정력이 없습니다. 모집 시기를 변화가 몰리는 때(학기 초, 입사·부서 이동, 조직의 AI 도입 시점)에 맞추는 것이 중요합니다.

## ③ 두 집단의 예비문항 설계표

### 3.1 구성 원칙

- **공통 핵심문항(C)**: 대학생판과 직장인판에서 `학업/업무`, `과제/업무` 같은 단어만 바뀝니다. 집단 간·시점 간 비교는 이 문항으로만 합니다.
- **맥락문항(U·W)**: 대학생은 과제·시험·수업 규정·조별과제, 직장인은 담당 업무·보안·승인·상사·동료 같은 맥락을 반영합니다. 내용 포괄성을 높이기 위한 문항이며, 집단 간 점수 비교에는 쓰지 않습니다.
- **보류(H)**: 기존 초안의 문항 가운데 다른 국면이나 비용 문항과 겹치는 문항입니다. 설계표에는 넣지 않고 문항은행에만 보관합니다.
- 응답자가 받는 국면 문항은 국면당 7개(공통 5 + 자기 집단 맥락 2)입니다.

### 3.2 '지난 7일 동안' 회상기간 검토

| 검토 항목 | 판단 |
|---|---|
| 반복조사와의 정합성 | 주 1회 조사이므로 회상기간을 7일로 두면 응답 구간이 겹치지도 비지도 않습니다. 기존 초안의 응답 창(수 05:00 발송~목 09:00 마감)과 맞습니다. |
| 회상 정확도 | 회상기간은 측정 개념의 변동 속도, 기억 부담, 용도에 따라 정해야 합니다(Norquist 외, 2012). 7일은 일상 행동 회상에서 흔히 쓰는 길이입니다. 다만 "생각이 며칠 사이에 바뀌었다"(S2-C04) 같은 문항은 7일 회상이 정확한지 인지면담에서 따로 확인합니다. |
| 상태형 문항과의 충돌 | "기본 방식이 되었다"(S4) 같은 **상태**는 7일 회상과 어색하게 결합될 수 있습니다. v0.1은 "지난 7일 동안 ~이었다"로 통일했지만, "지금 나는 ~"(현재 상태형)과 비교하는 분할 인지면담을 제안합니다. |

## ④ 측정도구 개발 절차와 표본 규모

> 표본 규모는 **계획값**입니다. 각 값 옆에 근거와 가정을 적었고, 최종값은 사전 몬테카를로 모의실험(Muthén & Muthén, 2002)으로 확정합니다.

|---|---|---|---|---|
| 4.1 전문가 내용타당도 | 관련성(I-CVI), 정의 대응도·**정의 변별도**(문항이 인접 국면보다 자기 국면 정의에 더 맞는가) | 전문가 8명(조직심리·교육심리·측정 전문가, 대학 교수학습 담당자, HR 실무자). 정의 변별도는 일반 평정자(대학생·직장인)를 추가 | 6~10명 패널에서 I-CVI ≥ .78을 기준으로 씀(Lynn, 1986; Polit & Beck, 2006). 정의 변별도 절차와 평정자 수는 Colquitt 외(2019)의 원문을 확인한 뒤 확정 | I-CVI ≥ .78, S-CVI/Ave ≥ .90, 정의 변별도 기준은 사전등록 |

| 4.4 EFA | 요인 수와 구조, 대안모형(5요인/병합/단일/양극/전개 IRT) | 약 400명(집단당 200), 4.5와 **다른 표본** | 필요한 표본은 공통성과 요인당 문항 수에 달려 있음(MacCallum 외, 1999; Mundfrom 외, 2005). 공통 25문항·5요인(요인당 5문항)·공통성 중간 가정에서 200~400명 수준. 7점 순서형 자료의 다분상관 추정을 고려해 상한 쪽을 택함 | 주부하 ≥ .40, 교차부하 차이 ≥ .20, 평행분석·EGA로 요인 수 확인 |

| 4.7 종단(주간)과 시점 간 측정동일성 | 개인 내 신뢰도, 시점 간 동일성, 국면 이동과 순서 검증 | 모집 약 360명(집단당 180, 셀당 45), 탈락 30% 가정 시 완료 약 250명 × 12주 | 개인 내·개인 간 신뢰도는 다층 CFA로 따로 추정(Geldhof 외, 2014; Lai, 2021). 12시점 전체를 한 모형에 넣으면 모수가 너무 많으므로 0·4·8·12주로 순서형 종단 동일성을 검정(Liu 외, 2017)하고, 다층 모형에서 부하 동일 제약을 비교. 6상태 이동 모형의 복원 가능성은 모의실험으로 확인(Nylund-Gibson 외, 2023) | 시점 간 부하·임계값 동일성 유지, 모의실험에서 상태 복원 정확도 충족 |

- 4.4~4.6은 [`docs/연구절차.md`](../docs/연구절차.md)의 5·6단계, 4.7은 7단계와 대응합니다.
- **같은 자료로 문항을 고르고 검증하지 않습니다.** 예비조사·EFA·CFA·종단 표본은 서로 겹치지 않게 모집합니다.

## ⑤ 반복조사 운영과 문항 버전관리

### 5.1 기본안: 동일 참여자 주간 종단조사

| 회차 | 받는 문항 | 예상 시간 |
|---|---|---|
| 0주(기준) | 배경 + 국면 35(공통 25 + 맥락 10) + E1 8 + 비용 5 + 관성 3 + 준거척도 | 15분 이내 |
| 1~12주(매주) | **공통 국면 25** + E1 8 + 비용 5 + 자기배치 1 + 주간 상황 3 + 주의 확인 1 + 성찰 1(선택) | 5분 내외 |
| 4·8·12주 | 위 문항 + 맥락 10 + 관성 3 | +2분 |
| 종료 | 0주와 같음 | 15분 이내 |

- **기존 초안과 달라진 점**: 기존 초안은 국면당 고정 2문항 + 순환 블록(계획결측 설계)이었습니다. 이 보고서는 **공통 핵심문항 25개를 매주 모두 받는 안**을 제안합니다. 이유는 (a) 시점 간 측정동일성은 같은 문항을 매주 받아야 검정할 수 있고, (b) 순환 블록은 문항별 주간 응답 수가 1/3로 줄어 주 단위 개인 점수의 신뢰도가 낮아지기 때문입니다. 응답 부담이 문제로 확인되면(예비조사 응답 시간 > 6분) 계획결측 설계(Graham 외, 2006)로 되돌리는 것을 수정 후보로 둡니다.
- 발송·알림·마감 시각은 기존 초안(수 05:00 발송, 목 09:00 마감)을 그대로 둡니다. 보고서 기준 시각(수 05:00)과 설문 발송 시각이 같다는 점은 미해결 쟁점 3에서 확인합니다.

### 5.2 문항 버전관리

상세 규칙은 [`item_bank/README.md`](../item_bank/README.md)에 정리했습니다. 요지는 다음과 같습니다.

1. **두 층 구조**: 수정안은 문항은행(`item_bank.csv`, bank v0.x)에서만 관리하고, 실제 조사에는 동결된 **조사판**(`releases/F{순번}-{대상}-{bank 버전}`)만 씁니다.
2. **조사 차수별 고정**: 한 패널(0~12주)이 진행되는 동안 조사판은 바꾸지 않습니다. 문항은행이 바뀌면 **다음 패널 0주**부터 적용합니다.
3. **패널 중간 예외**: 윤리 문제나 심각한 오해가 확인된 문항만 중단(삭제)하고, 대체 문항은 넣지 않습니다.
4. **ID와 개정**: ID는 재사용하지 않습니다. 경미한 문구 수정은 같은 ID에서 `rev`를 올리고, 측정 개념·국면·회상기간·척도가 바뀌면 새 ID를 줍니다.
5. **이전 자료와의 비교 가능성**

| 변경 유형 | 이전 자료와 비교 | 필요한 절차 |
|---|---|---|
| 문항 변경 없음 | 그대로 비교 | – |
| 경미한 문구 수정(`rev` +1) | 연결 검증을 통과하면 비교 | 새 패널 0주에 응답자를 반분해 이전·새 문구를 받고 DIF·동일성 확인 |
| 의미 변경(새 ID) | 직접 비교하지 않음 | 국면당 변경되지 않은 기준문항(3개 이상)으로 척도를 연결하거나, 공통 문항만으로 점수 산출 |
| 문항 추가 | 추가 문항을 뺀 점수로 비교 | 추가 문항은 별도 표시 |
| 문항 삭제 | 삭제 문항을 뺀 점수로 이전 자료를 다시 계산해 비교 | – |

- 모든 응답 행에 `form_id`와 문항별 `rev`를 기록합니다.

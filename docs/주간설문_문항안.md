# DTTM 6국면 주간 설문 문항안(측정도구 개발용)

대학생(1~4학년)과 직장인(1~4년차)을 대상으로 **매주 수요일 오전 5시(KST)에 발송하는 주간 설문**의 문항 풀과 운영안입니다. [`연구절차.md`](연구절차.md) 4단계(측정도구 개발)의 문항 풀 작성 기준(국면당 6~8문항, 총 36~48문항, 비용 문항과 E1 사건 문항 별도)을 따릅니다.

> **상태:** 연구자 초안입니다. 국면 정의는 이 저장소 문서의 국면 이름과 비용 역전 조건(C유지 > α × C전환)에서 끌어낸 **작업 정의**입니다. 명세서(2026-09-27 확장 초안)의 정의와 기존 24문항에 맞춰 대조한 뒤, 전문가 CVI와 인지면접을 거쳐야 합니다.

---

## 1. 설계 개요

| 항목 | 내용 |
|---|---|
| 목적 | 문항 풀(48문항+비용 9문항)의 분포, 국면 변별력, **주간 변화 민감도**, 집단 간 문항기능차이(DIF)를 확인해 예비 척도와 단축척도 후보를 고릅니다. |
| 대상 | 대학생 1~4학년, 직장인 재직 1~4년차. 학년·연차를 맞춘 **2집단 × 4수준 = 8셀** 설계입니다. |
| 변화 대상 | 두 집단 공통으로 **생성형 AI를 활용한 [학업/업무] 방식**으로 고정합니다(연구절차 0단계 권고). 문항의 `{새 방식}`에 이 문구를 넣습니다. |
| 표본 | 셀당 분석 표본 25명 이상(총 200명 이상). 탈락 30%를 고려해 셀당 35명, 총 약 280명을 모집합니다. |
| 기간 | 기준조사(0주) + 주간 조사 12회 + 종료조사. 대학생은 학기 중(개강 2주 차~기말고사 전 주)에만 운영합니다. |
| 위치 | 이 자료는 **개발용 패널**입니다. 6단계 본조사(EFA·CFA)와 7단계 종단조사에는 쓰지 않고 별도 표본을 받습니다. 척도 개발과 검증을 같은 자료로 하면 과적합이 됩니다(연구절차 1장 5·6번). |

### 1.1 왜 "수요일 05:00 발송"인가

- **05:00은 발송 시각이고 응답 시각이 아닙니다.** 새벽에 링크가 도착해 있으면 대학생은 등교·수업 전후, 직장인은 출근길이나 점심에 응답할 수 있습니다. 응답 시각은 자동 기록해 공변량으로 씁니다.
- **주중 한가운데**라 월요일(주초 부담)과 금요일(주말 기분) 효과를 피합니다.
- **간격이 정확히 7일**로 고정되어 HMM, 변화점 분석처럼 등간격을 가정하는 분석에 유리합니다.

| 시각(KST) | 내용 |
|---|---|
| 수 05:00 | 링크 발송(문자 또는 카카오 알림톡, 이메일 병행) |
| 수 12:30 | 1차 알림(미응답자) |
| 수 21:00 | 2차 알림(미응답자) |
| 목 09:00 | 응답 마감. 응답 창은 28시간입니다. |

- 마감 뒤 응답은 받지 않습니다. 회고 기간("지난 7일")이 다음 회차와 겹치지 않게 하기 위해서입니다.
- 시험 주간, 공휴일, 연휴는 그 주 응답에 **표시 변수**로 남깁니다. 설 연휴처럼 응답률이 크게 떨어질 주는 미리 건너뛰고 일정을 한 주 늦춥니다.

### 1.2 응답 부담 관리(계획결측 설계)

전체 문항(약 70문항)을 매주 받으면 8~10분이 걸려 12주 유지율이 떨어집니다. 그래서 다음처럼 나눕니다.

| 회차 | 받는 문항 | 예상 시간 |
|---|---|---|
| 0주(기준) | 배경 + 국면 문항 48 + 비용 9 + 준거척도 | 15분 이내 |
| 1~12주 | **고정 문항**(국면당 2개 = 10) + **순환 블록 A/B/C 중 하나**(국면당 2개 = 10) + E1 사건 8 + 비용 6 + 자기배치 1 + 주간 상황 3 + 주의 확인 1 + 성찰 1 | 5분 이내 |
| 4·8·12주 | 위 내용 + 관성 α 3문항 | +1분 |
| 종료 | 국면 문항 48 전체 + 준거척도 | 15분 이내 |

- 순환 블록은 응답자마다 시작 블록을 무작위로 정해(A→B→C 또는 B→C→A 등) 매주 각 블록이 같은 비율로 응답되게 합니다. 3형식 계획결측 설계(Graham 외, 2006)이므로 FIML이나 다중대체로 분석할 수 있습니다.
- 고정 문항은 국면별로 2문항을 처음에 연구자가 지정하고, 0주 자료에서 문항-국면 상관이 낮게 나오면 1주 차 전에 한 번만 바꿉니다. 그 뒤로는 바꾸지 않습니다.
- 아래 문항표의 **고정**과 **A/B/C** 칸이 이 배치입니다.

## 2. 공통 지시문과 응답 척도

**지시문(대학생판)**

> 이 설문은 **생성형 AI를 활용한 학업 방식**(이하 '새 방식')에 대해 여러분이 지금 어떤 상태에 있는지 묻습니다. '기존 방식'은 새 방식을 쓰기 전에 과제·공부를 해 오던 방법입니다. 정답은 없습니다. **지난 7일 동안(지난주 수요일부터 오늘까지)** 의 경험을 떠올리며 응답해 주세요.

**지시문(직장인판)**: "학업"을 "업무", "과제·공부"를 "업무"로 바꿉니다. 그 밖의 문구는 같습니다.

**응답 척도**: 7점 리커트(1 전혀 그렇지 않다 ~ 4 보통이다 ~ 7 매우 그렇다)

**표기 규칙**
- `{새 방식}` = 생성형 AI를 활용한 [학업/업무] 방식
- `[학업/업무]`, `[과제/업무]`, `[교수·조원/상사·동료]` = 대학생판/직장인판에서 바꾸는 단어. 바뀌는 단어를 이 세 가지로 제한합니다(연구절차 4단계 2번).
- (R) = 역문항. 국면 문항은 응답자가 "그 국면에 있을 때만" 높게 답하는 단봉형 반응을 보일 수 있으므로, 역문항은 국면당 최대 1개로 둡니다.

## 3. 국면별 작업 정의와 문항

### S0 전경합(Pre-contention)

- **작업 정의**: 새 방식이 있다는 것은 알지만, 기존 방식과 비교할 대상으로 떠오르지 않는 상태입니다. 기존 방식이 당연하고 안정적입니다.
- **진입/이탈**: 변화 대상을 인지하면 진입합니다. 두 방식을 비교하기 시작하면 S1로 넘어갑니다.
- **S1과의 구분**: S0에는 "비교·저울질"이 없습니다.

| 번호 | 문항 | 배치 |
|---|---|---|
| S0-1 | 지금의 [학업/업무] 방식을 바꿀 필요를 거의 느끼지 않는다. | 고정 |
| S0-2 | {새 방식}은 나와 별 관계없는 이야기처럼 느껴진다. | 고정 |
| S0-3 | {새 방식}에 대해 따로 알아보거나 생각해 본 적이 거의 없다. | A |
| S0-4 | 기존 방식만으로도 [학업/업무]를 충분히 잘 해낼 수 있다. | A |
| S0-5 | 주변에서 {새 방식} 이야기가 나와도 깊이 생각하지 않고 넘긴다. | B |
| S0-6 | {새 방식}과 기존 방식을 비교해 볼 이유가 없다고 느낀다. | B |
| S0-7 | {새 방식}이 내 [학업/업무]에 어떤 영향을 줄지 떠올린 적이 거의 없다. | C |
| S0-8 | {새 방식}을 써야 할지 고민한 적이 있다. (R) | C |

### S1 경합(Contention)

- **작업 정의**: 기존 방식과 새 방식이 서로 비교 대상이 되어, 장단점을 저울질하는 상태입니다. 끌림과 꺼림이 함께 있고, 시험적 탐색이 나타납니다.
- **진입/이탈**: 비교를 시작하면 진입합니다. 기존 방식이 실제로 흔들리기 시작하면 S2로 넘어갑니다.
- **S2와의 구분**: S1은 "생각 속 비교"이고 기존 방식은 아직 안정적입니다. S2는 실제 행동과 마음이 오락가락합니다.

| 번호 | 문항 | 배치 |
|---|---|---|
| S1-1 | 기존 방식과 {새 방식} 중 어느 쪽이 나은지 따져 보고 있다. | 고정 |
| S1-2 | 기존 방식을 계속할 이유와 바꿀 이유가 비슷하게 맞서 있다. | 고정 |
| S1-3 | {새 방식}의 장점과 단점을 함께 떠올리게 된다. | A |
| S1-4 | {새 방식}에 마음이 끌리면서도 한편으로는 꺼려진다. | A |
| S1-5 | {새 방식}을 시험 삼아 조금 써 보거나 살펴본 적이 있다. | B |
| S1-6 | 주변 사람들이 {새 방식}을 어떻게 쓰는지 관심 있게 지켜본다. | B |
| S1-7 | {새 방식}에 관한 정보를 찾아보거나 다른 사람에게 물어본 적이 있다. | C |
| S1-8 | 아직은 어느 쪽으로도 마음을 정하지 않았다. | C |

### S2 경계(Boundary)

- **작업 정의**: 기존 방식에 균열이 생기고, 두 방식의 경계에서 생각과 행동이 오락가락하는 불안정한 상태입니다. 기존 방식을 유지하는 수고가 체감되기 시작합니다. 조기경보 신호(변동성·자기상관 증가)가 나타날 것으로 가정하는 국면입니다.
- **진입/이탈**: 기존 방식이 잘 맞지 않는 경험이 반복되면 진입합니다. "더 이상 이대로는 안 된다"는 판단이 서면 S3로 넘어갑니다.
- **S3와의 구분**: S2는 "흔들림"이고 방향이 정해지지 않았습니다. S3는 방향이 정해졌고 실행만 남았습니다.

| 번호 | 문항 | 배치 |
|---|---|---|
| S2-1 | 같은 종류의 [과제/업무]인데도 어떤 때는 기존 방식, 어떤 때는 {새 방식}으로 하는 등 오락가락한다. | 고정 |
| S2-2 | 두 방식 사이에서 어정쩡하고 불안정한 상태라고 느낀다. | 고정 |
| S2-3 | 기존 방식이 예전만큼 잘 맞지 않는다고 느낀 순간이 있었다. | A |
| S2-4 | {새 방식}에 대한 내 생각이 며칠 사이에도 자주 바뀐다. | A |
| S2-5 | 기존 방식을 고수하는 데 드는 수고가 눈에 띄기 시작했다. | B |
| S2-6 | 작은 일(과제 하나, 누군가의 한마디)에도 마음이 이쪽저쪽으로 흔들린다. | B |
| S2-7 | 기존 방식으로 하다가 중간에 {새 방식}으로 바꾸거나, 그 반대로 한 적이 있다. | C |
| S2-8 | 어느 방식으로 할지 신경이 쓰여 [학업/업무]에 집중하기 어려웠던 적이 있다. | C |

### S3 임계(Critical)

- **작업 정의**: 기존 방식을 유지하는 부담이 바꾸는 부담을 넘어서는 지점(비용 역전)에 다다른 상태입니다. 마음은 새 방식으로 기울었고, 작은 계기만 있으면 전이가 일어납니다.
- **진입/이탈**: 전환 의도와 계획이 서면 진입합니다. E1 사건이 일어나면 이탈합니다. 계기 없이 오래 머물거나 S2로 되돌아갈 수도 있습니다.
- **E1과의 구분**: S3는 "의도와 준비"이고, E1은 "실제로 일어난 행동"입니다. S3 문항에는 이미 일어난 사용 행동을 넣지 않습니다.

| 번호 | 문항 | 배치 |
|---|---|---|
| S3-1 | 지금처럼 기존 방식을 계속하기는 어렵다고 느낀다. | 고정 |
| S3-2 | 조금만 계기가 생기면 바로 {새 방식}으로 넘어갈 것 같다. | 고정 |
| S3-3 | 바꿀지 말지 결정을 더 미룰 수 없다고 느낀다. | A |
| S3-4 | 마음은 이미 {새 방식} 쪽으로 기울었고 실행만 남았다. | A |
| S3-5 | {새 방식}으로 바꾸기 위한 구체적인 계획(언제, 무엇부터)을 세웠다. | B |
| S3-6 | 기존 방식을 지키려는 마음이 거의 남아 있지 않다. | B |
| S3-7 | 다가오는 [과제/업무] 마감이나 일정을 계기로 바꾸겠다고 정해 두었다. | C |
| S3-8 | 기존 방식을 붙잡고 있는 것이 이제는 버겁게 느껴진다. | C |

> S3-8과 아래 비용 문항 CM-3은 표현이 가깝습니다. CVI 단계에서 정의 변별도를 따로 확인하고, 둘 중 하나만 남깁니다.

### E1 전이(Transition) — 사건 문항

E1은 리커트 요인이 아니라 **관찰 가능한 사건**으로 측정합니다(README, 연구절차 2단계). 국면 점수로 전이를 정의하는 순환논증을 막기 위해, 행동·날짜·확인 가능한 흔적을 묻습니다. 매주 8문항을 모두 받습니다.

| 번호 | 문항 | 응답 형식 |
|---|---|---|
| E1-1 | 지난 7일 동안 {새 방식}을 실제 [과제/업무]에 **처음으로** 사용했다. | 예/아니오/이전에 이미 사용함 → "예"이면 요일 선택 + 어떤 [과제/업무]였는지 한 줄 |
| E1-2 | 지난 7일 동안 기존 방식의 사용을 **일부러 멈춘** [과제/업무]가 있다. | 예/아니오 → "예"이면 요일 + 한 줄 |
| E1-3 | 지난 7일 동안 {새 방식}을 쓰기 위한 준비(계정 만들기, 설치, 구독, 사용법 교육 등)를 마쳤다. | 예/아니오/이전에 이미 마침 |
| E1-4 | 지난 7일 동안 내 [과제/업무] 가운데 {새 방식}으로 처리한 비율은? | 0% / 1~25% / 26~50% / 51~75% / 76~100% |
| E1-5 | 지난 7일 동안 {새 방식}을 써서 완성한 결과물을 제출하거나 보고했다. | 예/아니오 |
| E1-6 | 지난 7일 동안 [교수·조원/상사·동료]에게 앞으로 {새 방식}으로 하겠다고 알렸다. | 예/아니오 |
| E1-7 | {새 방식}으로 바꿨다가 지난 7일 안에 기존 방식으로 **되돌아간** 적이 있다. | 예/아니오 → "예"이면 이유 한 줄 |
| E1-8 | 위 행동을 확인할 수 있는 기록(제출 이력, 파일, 사용 기록)이 있다. | 예/아니오/해당 없음 → 로그 제공 별도 동의자만 연결 |

- **E1 판정 규칙(초안)**: E1-1 또는 E1-2가 "예"이면서 E1-4가 26% 이상인 첫 주를 E1 시점으로 봅니다. 사전등록에서 확정합니다.
- E1-7은 회귀 사건입니다. 이력효과(H4) 분석에서 전진 전이와 회귀 전이 시점의 비용비를 비교할 때 씁니다.
- 대학생은 LMS·학습도구 로그, 직장인은 시스템 사용 기록과 E1 자기보고의 일치도(같은 주 또는 ±1주)를 보고합니다(연구절차 7-S 관문).

### S4 재구조화(Restructuring)

- **작업 정의**: 새 방식을 중심으로 [학업/업무]의 순서, 역할, 습관, 자기 인식이 다시 짜인 상태입니다. 기존 방식으로 돌아가는 문턱이 높아집니다(이력효과).
- **진입/이탈**: E1 뒤 새 방식이 반복·안정되면 진입합니다. 회귀 사건(E1-7)이 반복되면 이전 국면으로 돌아갈 수 있습니다.
- **E1과의 구분**: E1은 한 번의 사건이고, S4는 그 뒤에 자리 잡은 상태입니다.

| 번호 | 문항 | 배치 |
|---|---|---|
| S4-1 | 이제 {새 방식}이 내 [학업/업무]의 기본 방식이 되었다. | 고정 |
| S4-2 | 기존 방식으로 돌아가는 것은 이제 상상하기 어렵다. | 고정 |
| S4-3 | {새 방식}을 쓸 때 따로 의식하지 않아도 자연스럽게 손이 간다. | A |
| S4-4 | {새 방식}에 맞춰 [학업/업무]의 순서나 시간 배분을 다시 짰다. | A |
| S4-5 | {새 방식}을 쓰면서 내가 맡은 역할이나 하는 일의 내용이 달라졌다. | B |
| S4-6 | {새 방식}과 관련해 나만의 규칙이나 요령이 생겼다. | B |
| S4-7 | {새 방식}을 다른 사람에게 알려 주거나 도와준 적이 있다. | C |
| S4-8 | {새 방식}으로 [학업/업무]를 하는 것이 '나다운' 방식이라고 느낀다. | C |

## 4. 비용 문항(유지비용·전환비용·관성 α)

세 요소는 **따로** 측정합니다(README 2단계). 비용비 R = C유지 / (α × C전환)를 주별로 계산해 S3→E1 전이 예측(H3)에 씁니다. 응답 척도는 국면 문항과 같은 7점입니다.

| 번호 | 요소 | 문항 | 주기 |
|---|---|---|---|
| CM-1 | 유지비용 | 기존 방식을 계속 쓰면 시간이나 노력이 더 든다. | 매주 |
| CM-2 | 유지비용 | 기존 방식을 고수하면 뒤처지거나 불이익을 받을 것 같다. | 매주 |
| CM-3 | 유지비용 | 기존 방식을 유지하는 것이 점점 불편해지고 있다. | 매주 |
| CT-1 | 전환비용 | {새 방식}을 익히는 데 시간과 노력이 많이 든다. | 매주 |
| CT-2 | 전환비용 | {새 방식}으로 바꾸면 처음에는 실수가 늘거나 성과가 떨어질 것 같다. | 매주 |
| CT-3 | 전환비용 | {새 방식}으로 바꾸려면 돈, 교육, 주변의 협조 같은 조건이 더 필요하다. | 매주 |
| IA-1 | 관성 α | 익숙한 방식을 바꾸는 것 자체가 나에게는 큰 부담이다. | 0·4·8·12주 |
| IA-2 | 관성 α | 더 나은 방법이 있어도 하던 대로 하는 편이다. | 0·4·8·12주 |
| IA-3 | 관성 α | 일단 자리 잡은 습관은 웬만해서는 바꾸지 않는다. | 0·4·8·12주 |

- α는 성향에 가까운 변수로 보고 4주 간격으로만 받습니다. 주간 변동이 크게 나오면 매주로 바꾸는 것을 사전등록에서 검토합니다.
- 비용 문항이 국면 문항(특히 S2-5, S3-8)과 같은 요인으로 묶이면 국면과 비용이 개념적으로 겹친다는 뜻입니다. EFA에서 따로 확인합니다.

## 5. 매주 함께 받는 문항

| 번호 | 문항 | 용도 |
|---|---|---|
| P-1 | **자기배치**: "지금 나는 다음 중 어디에 가장 가깝습니까?" 6개 짧은 기술문(S0~S4와 '막 바꾼 직후' = E1)을 무작위 순서로 제시하고 하나를 고릅니다. 기술문에 국면 이름은 쓰지 않습니다. | 국면 문항의 수렴타당도, 카드 분류 결과와의 대조 |
| W-1 | 이번 주에 시험·과제 마감(대학생) 또는 주요 마감·평가(직장인)가 있었다. (예/아니오) | 주간 상황 공변량 |
| W-2 | 이번 주에 수업·조직에서 {새 방식} 관련 공지, 교육, 규정 변경이 있었다. (예/아니오/모름) | 외부 계기(전이 촉발 요인) |
| W-3 | 이번 주 [학업/업무]량은 평소와 비교해 어땠나요? (훨씬 적음 ~ 훨씬 많음, 5점) | 주간 상황 공변량 |
| Q-1 | 이 문항에는 '3'을 선택해 주세요. | 불성실 응답 탐지(위치는 매주 무작위) |
| R-1 | 이번 주 {새 방식}과 관련해 기억에 남는 일을 1~2문장으로 적어 주세요. (선택) | 성찰일지. 전환 신호의 질적 코딩 |

자기배치 기술문 예시(인지면접에서 다듬습니다)
1. 새 방식이 있다는 건 알지만, 나와는 별로 상관없다.
2. 기존 방식과 새 방식 중 무엇이 나을지 따져 보고 있다.
3. 두 방식 사이에서 왔다 갔다 하며 마음이 자주 바뀐다.
4. 이제 바꿔야 한다고 마음먹었고, 실행만 남았다.
5. 최근에 실제로 새 방식으로 바꾸기 시작했다.
6. 새 방식이 이미 내 일상적인 방식으로 자리 잡았다.

## 7. 문항 선별에 쓰는 분석과 기준(초안)

이 패널은 문항을 **고르는** 단계입니다. 아래 기준은 예비조사 관문(연구절차 5단계)과 함께 사전등록에서 확정합니다.

| 분석 | 보는 것 | 남기는 기준(예시) |
|---|---|---|
| 문항 기술통계 | 분포, 바닥·천장, 결측 | 한쪽 끝 응답 80% 미만, 결측 5% 미만 |
| 0주 EFA(다분상관, 사각회전) | 문항이 의도한 국면에 묶이는지 | 주부하 ≥ .40, 교차부하 차이 ≥ .20 |
| 다층 CFA(주 ⊂ 사람) | 개인 내 신뢰도(ω-within)와 개인 간 신뢰도(ω-between) | 국면별 ω-within ≥ .60, ω-between ≥ .70 |
| 변화 민감도 | 개인 내 주간 표준편차, E1 전후 평균 변화 | 국면 안에서 민감도 상위 문항을 단축척도 후보로 |
| 전개 IRT(GGUM) | 문항 위치가 S0→S4 순서로 배열되는지 | 위치 순서가 의도한 국면 순서와 어긋나는 문항 검토 |
| 자기배치와의 대응 | 자기배치 국면에서 해당 국면 점수가 가장 높은지 | 국면별 일치율 보고 |
| DIF | 대학생·직장인, 학년·연차에 따른 문항기능차이 | 집단 간 DIF가 큰 문항은 표현 수정 또는 탈락 |
| E1 사건 일치도 | 자기보고 E1과 로그 기록 | 같은 주 또는 ±1주 일치 70% 이상 |

- 8셀(집단 × 학년·연차) 각각의 측정동일성은 표본이 작아 검증하지 않습니다. **집단(2개)** 수준의 다집단 분석을 하고, 학년·연차는 MIMIC 모형의 공변량으로 넣어 DIF를 봅니다. 8셀 수준 동일성은 6단계 본조사에서 다룹니다.
- 최종적으로 국면당 5개 이상(예비 척도)을 남기고, 그 안에서 변화 민감도가 높은 3~4개를 단축척도 후보로 표시합니다.

## 8. 대상별로 유의할 점

- **대학생 4학년과 직장인 1년차**는 졸업·취업으로 맥락이 바뀌는 시기라 변화 대상과 무관한 변동이 클 수 있습니다. 취업 준비 여부(4학년), 수습 여부(1년차)를 배경 문항에 추가하는 것을 권합니다.
- **대학생 1학년**은 "기존 방식"이 고등학교 시절 방식일 수 있습니다. 인지면접에서 '기존 방식'을 어떻게 이해하는지 꼭 확인합니다.
- **연구자가 성적을 매기는 수업의 학생은 모집하지 않습니다**(연구절차 0단계 IRB 보호 조치). 참여 보상은 성적과 연결하지 않습니다.
- **직장인**은 회사 메신저가 아닌 개인 연락처로 발송합니다. 응답 내용은 회사에 공유되지 않는다는 점을 동의서에 적습니다.
- 05:00 발송은 알림음이 수면을 방해할 수 있습니다. 동의 단계에서 발송 시각을 알리고, 문자 대신 이메일만 받는 선택지를 줍니다.

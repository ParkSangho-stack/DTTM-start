## 1. 제2판의 핵심 구조(요약)

- **2층 상태공간:** 체제 층 R(R₀ 기존, R₁ 신규) × 국면 층 P. R₀ 안에 B(기저 안정)·S0·S1·S2·S3, R₁ 안에 N(전이 직후 미안정)·S4.
- **E1은 국면이 아니라 체제 전환(R₀→R₁) 사건**입니다. 논문에서는 "5개 잠재 국면과 1개 전환 사건"으로 병기합니다.
- **국면별 증거 양식:** 수준(설문)·동태(일지/ESM)·사건(기록). S2의 설문 문항은 대리 지표이며, 동태 지표와의 수렴(P4) 전에는 설문만으로 S2를 판정하지 않습니다.
- **전향적 판정 / 후향적 검증 분리**로 순환성을 막습니다.
- **문항 유형 부호:** [누] 누적형, [특] 국면특이형, [사] 사건형. 국면마다 [특] 문항 2개 이상.
- **비용식 Cₘ > α·Cₜ**를 로그 변환한 이산시간 생존모형의 계수 등식 제약(β₁ = −β₂ = −β₃ > 0)으로 검정하고, cusp 모형과 이력현상(P9)을 추가합니다.
- **명제 P1~P11**과 기각 기준, 전이행렬 사전 명세(12장), 이중 판정 5단계 알고리즘(15장).

## 2. 현재 저장소 문서와의 대조(1차)

W00 주간보고(`weekly/2026-10-17_W00.md`) 6.3절 쟁점 1·4에 대한 1차 대조입니다. 아래는 모두 **검토 후보**이며, 연구자 승인 전에는 문항은행(`item_bank/item_bank.csv`)에 반영하지 않습니다(`item_bank/README.md` 5장 규칙).

### 2.1 국면 정의

| 국면 | 현재 작업 정의(W00 2.1) | 제2판 정의 | 차이의 성격 |
|---|---|---|---|
| S0 | 새 방식이 대안으로 떠오르지 않음, 비교 부재 | 표면 기능은 유지되나 **설명되지 않은 불일치가 반복**, 문제 명명 유보, 공개적 대안 경쟁 부재 | 개념 변경. 현재 S0 문항(변화 필요 부재·비교 부재)은 제2판의 B(기저 안정)에 더 가까움 |
| S1 | 두 방식을 비교·저울질, 기존 방식은 안 흔들림 | **양립하기 어려운 두 요구의 명명** + 선택 제약 반복 + 기능 유지 | 부분 일치(기능 유지). 핵심이 '방식 비교'에서 '요구 충돌'로 이동 |
| S2 | 두 방식 사이를 오가는 불안정, 주간 변동 증가 | **개인 내 기준선 대비 교란 후 회복 지연**, 분산 증가, 차질 전파 | 개념 변경. 기준선과 교란 사건 로그가 필요 |
| S3 | 방향 확정 + 계획, 아직 미실행 | **비용 평가 + 가용 대안·실행 조건 + 실행 준비 개시**를 각각 독립 측정 | 부분 일치(미실행). '방향 확정'보다 세 요소의 동시 충족이 기준 |
| E1 | 관찰 가능한 사건(사용 비율 ≥ 26% 규칙 초안) | 체제 전환 사건. **기록 1건 + 자기보고/제3자 확인 1건**, 평정자 2인 독립 부호화 | 사건 취급은 일치. 판정 규칙을 제2판 기준으로 재작성 필요 → 쟁점 4는 "사건으로만 본다"로 정리됨 |
| S4 | 새 방식 중심 재편, 복귀 곤란 | **반복 · 정렬 · 복원력(교란 후 새 방식 복귀)** 세 차원, 확정은 관찰창 종료 후 | 부분 일치. 이전 E1 직후 구간 N을 따로 둠 |
| B, N | 없음 | B 기저 안정, N 전이 직후 미안정 | 신규 상태 |

### 2.2 측정 설계

| 항목 | 현재 저장소 | 제2판 | 검토 필요 사항 |
|---|---|---|---|
| 회상 기간 | 모든 국면 문항 '지난 7일' | 수준 문항 '지난 한 달', 일지 '오늘', 사건형 '지난 조사 이후' | 주간 패널을 유지할지, 제2판의 월별 패널 + 측정 버스트로 바꿀지 결정 |
| 응답 척도 | 7점(L7) 중심 | 수준 문항 5점 빈도 척도, 사건형 예/아니오 + 날짜·기록 유형 | W00 쟁점 7(빈도 척도 여부)과 연결 |
| 문항 유형 | 부호 없음 | [누]/[특]/[사] 부호, 국면당 [특] ≥ 2 | 문항은행에 `item_type` 열 추가 후보 |
| 측정모형 | EFA/CFA 대안모형 비교 중심 | LCA·LTA·이상점 IRT(GGUM) 추가 | W00 쟁점 6(전개 IRT)과 일치 |
| 변화 대상 | 생성형 AI 활용 방식 | 실례는 대학 직원의 업무 방식 변화, 변화 대상은 참여자별 특정 | W00 쟁점 2와 연결 |
| 명세서 문항 | 대조 불가 | S0~S4 각 4문항 + E1 4문항(24문항) + 일지 D-1~D-3 | 문항은행 각 문항과 1:1 대조표 작성(다음 주간보고 과제) |

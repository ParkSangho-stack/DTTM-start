# DTTM 예비문항 인지면담 프로토콜(초안)

> **상태:** 초안입니다(W02, 2026-10-28). 면담 대상 문항은 문항은행 v0.2가 승인된 뒤 확정합니다. 면담은 IRB 승인 뒤에만 진행합니다. 모든 문항은 **개발 중인 예비문항**입니다.

## 1. 목적

- 응답자가 문항을 연구자가 의도한 뜻으로 이해하는지 확인합니다(COSMIN의 이해 가능성 기준; Terwee 외, 2018).
- 특히 다음 네 가지를 확인합니다.
  1. **회상기간**: '지난 7일', '지난 한 달', '지난 조사 이후' 가운데 응답자가 실제로 어느 기간을 떠올리는지
  2. **기존 방식**: 대학생 1학년과 직장인 1년차가 '기존 방식'을 무엇으로 이해하는지(명세서의 R₀ = 현재 우세한 방식)
  3. **[변화 대상]**: 대상 문구를 하나의 구체적 방식으로 떠올리는지
  4. **"도입 이전과 비교하여"**: 비교 기준 시점을 떠올릴 수 있는지(S2 문항. W01 쟁점 C)

## 2. 대상과 라운드

| 항목 | 내용 |
|---|---|
| 라운드 | 2~3라운드. 라운드 사이에 문항을 고치고, 고친 문항을 다음 라운드에서 다시 확인합니다(Willis, 2005). |
| 라운드당 인원 | 8명: 대학생 1~4학년 각 1명, 직장인 1~4년차 각 1명 |
| 형식 | 일대일 대면 또는 화상, 45~60분, 녹음(동의 시) |
| 제외 | 연구자가 성적을 매기는 수업의 학생, 연구자와 같은 부서의 직원 |

## 3. 진행 순서

1. **안내와 동의**(5분): 연구 목적, 녹음, 자료 보관, 언제든 중단할 수 있음을 안내합니다. "문항을 평가하는 것이지 응답자를 평가하는 것이 아니다"라고 말합니다.
2. **사고발화 연습**(5분): 연습 문항 1개("지난 한 달 동안 아침을 몇 번 거르셨나요?")로 소리 내어 생각하는 방법을 연습합니다.
3. **문항 응답과 사고발화**(25~30분): 응답자가 문항을 읽고 답하면서 떠오르는 생각을 말합니다. 면담자는 끼어들지 않습니다.
4. **탐침 질문**(15분): 아래 4장의 탐침을 문항별로 묻습니다. 사고발화에서 이미 답이 나온 탐침은 건너뜁니다.
5. **자기배치와 마무리**(5분): 6개 국면 기술문 카드(국면 이름은 가림)를 보여 주고 지금 자신에게 가장 가까운 것을 고르게 한 뒤, 그 이유를 묻습니다.

## 4. 탐침 질문

| 확인 대상 | 탐침 | 적용 문항 |
|---|---|---|
| 회상기간 | "이 질문에 답할 때 어느 기간을 떠올리셨나요? 언제부터 언제까지인가요?" | 모든 수준 문항 |
| 회상 정확도 | "그 기간에 있었던 일을 하나 예로 들어 주시겠어요?" | 빈도·사건 문항 |
| 기존 방식 | "여기서 '기존 방식'이 무엇을 말한다고 생각하셨나요?" | 기존 방식이 들어간 문항 전부 |
| 변화 대상 | "[변화 대상]이라고 했을 때 구체적으로 무엇이 떠올랐나요?" | 처음 나오는 문항 2개 |
| 비교 기준 | "'도입 이전'이 언제쯤이라고 생각하셨나요? 그때를 기억하실 수 있나요?" | S2 문항 |
| 국면특이형 | "이 문장이 지금은 맞는데, 나중에도 계속 맞을 것 같으신가요?" | [특] 문항 |
| 사건형 | "'처음 적용했다'는 것이 어떤 일을 뜻한다고 보셨나요? 시험 삼아 한 번 써 본 것도 포함되나요?" | E1 문항 |
| 응답척도 | "왜 그 숫자를 고르셨나요? 한 칸 위·아래와 어떻게 다른가요?" | 응답이 중간값인 문항 |
| 맥락 적합성 | "대학생(직장인)인 본인에게 이 상황이 실제로 있을 수 있나요?" | 맥락문항(U·W) |
| 민감성 | "답하기 불편하거나 사실대로 답하기 어려운 문항이 있었나요?" | 마지막에 전체 |

## 5. 기록과 판정

- 문항마다 문제를 다음 부호로 기록합니다: **C** 이해(단어·문장), **R** 회상(기간·기억), **J** 판단(어떤 답을 고를지), **S** 응답 선택지, **X** 맥락 부적합, **N** 민감성.
- 같은 문제가 한 라운드에서 2명 이상에게 나타나면 수정 후보로 올립니다.
- 수정 후보는 문항은행 규칙(`item_bank/README.md` 3·5장)에 따라 `rev` 증가 또는 새 ID로 처리하고, 연구자 승인 뒤 반영합니다.
- 라운드별 기록표: 문항 ID / 응답자 ID(집단·학년·연차) / 부호 / 응답자 발언 요약 / 면담자 판단 / 수정안

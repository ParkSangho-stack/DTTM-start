# DTTM 국면 문항 전문가 평정지(초안)

> **상태:** 양식 초안입니다(W01, 2026-10-21). 평정 대상 문항은 문항은행 v0.2가 승인된 뒤 채웁니다. 아래 예시 행은 명세서 제2판 문항으로 양식을 보여 주기 위한 것입니다. 모든 문항은 **개발 중인 예비문항**입니다.

## 1. 평정자 안내문

이 평정지는 '동태적 임계전이모형(DTTM)'의 국면을 측정하려는 예비문항이 각 국면의 정의에 얼마나 잘 맞는지 평가하는 데 쓰입니다. 국면 정의는 「DTTM 6국면 상세 조작적 명세서」 제2판(2026-09-27)을 따릅니다. 정답은 없습니다. 문항을 읽을 때 응답자가 대학생(1~4학년) 또는 입사 1~4년차 직장인이라고 생각해 주세요.

평정은 세 부분입니다.
- **A. 관련성(I-CVI)**: 문항이 표시된 국면을 측정하는 데 얼마나 관련 있는지 평가합니다.
- **B. 정의 대응도와 변별도**: 문항이 5개 국면 정의(S0~S4) 각각에 얼마나 잘 맞는지 평가합니다. 이때 문항의 국면 표시는 가립니다.
- **C. 자유 의견**: 이해하기 어려운 표현, 대학생·직장인 중 한쪽에만 맞는 표현, 빠진 내용을 적습니다.

## 2. 국면 정의 카드(평정자에게 제공)

| 국면 | 정의(명세서 제2판 요약) |
|---|---|
| S0 전경합 | 기존 방식의 겉보기 기능은 유지되지만, 설명되지 않은 어긋남이 반복된다. 무엇이 문제인지 아직 이름 붙이지 않았고, 대안이 공개적으로 경쟁하지 않는다. |
| S1 경합 | 양립하기 어려운 두 요구가 실제로 활성화되어 선택을 제약한다. 기존 방식으로도 일은 대체로 처리된다. |
| S2 경계 | 평소(기준선)와 비교해, 작은 차질 뒤 원래 흐름으로 돌아오는 데 더 오래 걸리고 수행의 기복이 커졌다. |
| S3 임계 | 유지 부담을 구체적으로 평가했고, 실행 가능한 대안과 조건을 확인했으며, 실행 준비를 시작했다. 아직 실행하지는 않았다. |
| S4 재구조화 | 전이 뒤 새 방식이 반복되고, 역할·자원·동료 기대와 맞춰졌으며, 문제가 생겨도 새 방식으로 복귀한다. |

E1(전이)은 국면이 아니라 사건이므로 B 부분의 평정 대상에서 뺍니다. E1 문항은 A 부분에서만 "사건을 확인하는 데 적절한가"로 평정합니다.

## 3. A. 관련성 평정(4점)

1 = 관련 없음, 2 = 상당한 수정이 있어야 관련 있음, 3 = 약간 수정하면 관련 있음, 4 = 매우 관련 있음

| 문항 ID | 표시 국면 | 문항 | 1 | 2 | 3 | 4 | 의견 |
|---|---|---|---|---|---|---|---|
| (예) S1-C06 | S1 | 한 요구에 맞추면 다른 중요한 요구를 포기해야 하는 상황이 반복되었다. | ☐ | ☐ | ☐ | ☐ | |

- 계산: I-CVI = 3 또는 4로 평정한 전문가 수 / 전체 전문가 수. 기준 ≥ .78(전문가 6~10명; Lynn, 1986; Polit & Beck, 2006). S-CVI/Ave ≥ .90.

## 4. B. 정의 대응도·변별도 평정(7점)

각 문항을 읽고 **5개 국면 정의 각각에** 대해 "이 문항이 이 정의를 얼마나 잘 나타내는가"를 평정합니다. 1 = 전혀 나타내지 않음 ~ 7 = 매우 잘 나타냄. 문항의 국면 표시는 보여 주지 않고, 문항 순서는 평정자마다 무작위로 섞습니다.

| 문항(무작위 순서) | S0 | S1 | S2 | S3 | S4 |
|---|---|---|---|---|---|
| (예) 실제로 바꿀 수 있는 대안과 그 실행 조건을 확인했다. | 1~7 | 1~7 | 1~7 | 1~7 | 1~7 |

- 정의 대응도: 의도한 국면 정의에 대한 평균 평정.
- 정의 변별도: 의도한 국면 평정과 **인접 국면**(예: S2 문항이면 S1·S3) 평정의 차이. 인접 국면을 비교 대상으로 삼는 이유는 DTTM의 핵심 쟁점이 인접 국면 구별이기 때문입니다.
- 평정 절차와 판정 기준은 Colquitt 외(2019)의 원문을 확인한 뒤 사전등록에서 확정합니다. 이 양식의 7점 척도와 '인접 국면 비교'는 확정 전 초안입니다.
- 평정자: 전문가 패널(8명)과 별도로, 대학생·직장인 일반 평정자에게도 같은 B 부분을 받는 안을 검토합니다.
